# IP-NET Hosting 1

Documentația proiectului **IP-NET Hosting 1**.

## Identitate
- Nume proiect: **IP-NET Hosting 1**
- Aplicație: **IP-NET Hosting**
- Application ID: `ro.ipnet.hosting`
- Panou: https://ptero.ip-net.ro
- Interfață: negru și roșu, în stilul IP-NET

## Obiectiv
Aplicație Android nativă pentru administrarea serverelor Pterodactyl, cu o interfață clară și instrumente rapide de control.

## Funcții
- Conectare prin Client API Key.
- Listarea serverelor și afișarea resurselor.
- Pornire, oprire și repornire.
- Consolă live.
- Manager de fișiere.
- Administrarea backup-urilor și bazelor de date.
- Gestionarea programărilor, utilizatorilor și alocărilor de rețea.

## Reguli de proiect
- Se păstrează identitatea vizuală IP-NET.
- Denumirile și documentația folosesc exclusiv identitatea IP-NET.
- Cheile API nu se publică și nu se includ în codul sursă.
