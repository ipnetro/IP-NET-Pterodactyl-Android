# Raportarea problemelor de securitate

Folosește o versiune disponibilă în [GitHub Releases](https://github.com/ipnetro/IP-NET-Pterodactyl-Android/releases).

Pentru a raporta o problemă de securitate, folosește funcția **Report a vulnerability** din fila **Security** a repository-ului, dacă este disponibilă. Dacă nu este disponibilă, contactează administratorul prin [profilul GitHub IP-NET](https://github.com/ipnetro).

Nu publica tokenuri, chei API, parole, date ale serverelor sau detalii exploatabile într-un issue public. Include pașii de reproducere și versiunea aplicației într-un mesaj privat.
